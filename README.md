# «Посмотри в окно»

Вторая проектная работа по фронтенд-разработке в Яндекс Практикуме. Страница позволяет смотреть видеозаписи из разных городов, фильтровать их по городу и времени суток и переключаться между карточками видео.

## Возможности

- Поиск видео по городу и времени суток (утро, день, ночь).
- Переключение между видеозаписями.
- Загрузка дополнительных карточек кнопкой «Показать ещё».
- Отображение индикатора загрузки и сообщений об ошибках.
- Стили для наведения, нажатия, фокуса и выбранной карточки.

## Технологии

HTML5, CSS3 (Flexbox, псевдоэлементы, состояния интерактивных элементов, object-fit) и JavaScript. Логика получения видео и обработки поиска предоставлена в стартовом проекте Яндекс Практикума. Основные стили интерфейса реализованы в рамках проектной работы.

## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Whatesigma12/posmotri-v-okno-ad.git
   ```

2. Откройте папку проекта в VS Code.
3. Запустите `index.html` в браузере (например, с помощью Live Server).

Сборка и установка зависимостей не требуются. Для загрузки видео необходимо подключение к интернету: приложение обращается к API `https://v-content.practicum-team.ru`.

## Проверка

После отправки изменений на GitHub автопроверка запускается во вкладке **Actions**. Перед сдачей нужно также проверить соответствие макету и работу поиска, выбора карточек, прокрутки, кнопок, состояний фокуса и ошибок в браузере.
